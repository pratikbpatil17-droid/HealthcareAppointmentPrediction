\# Healthcare Appointment Analytics \& No-Show Prediction



\## About the Project

Healthcare Appointment Analytics \& No-Show Prediction is a Python-based web application designed to manage healthcare appointments and predict the possibility of patients missing their scheduled appointments.



\## Features

\- Patient Management

\- Doctor Management

\- Appointment Booking

\- Appointment Analytics Dashboard

\- Machine Learning-Based No-Show Prediction

\- Database Integration



\## Technologies Used

\- Python

\- Flask

\- Machine Learning

\- SQLite

\- HTML, CSS and JavaScript

\- Pandas and Scikit-learn (if used in the implementation)



\## Project Structure

\- `app.py` — Main Flask application

\- `database.py` — Database operations

\- `model.py` — Prediction model

\- `templates/` — HTML templates

\- `static/` — CSS, JavaScript and static assets

\- `dataset/` — Dataset files

\- `requirements.txt` — Python dependencies



\## Installation and Setup



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/pratikbpatil17-droid/HealthcareAppointmentPrediction.git

&#x20;  ```



2\. Open the project folder:



&#x20;  ```bash

&#x20;  cd HealthcareAppointmentPrediction

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



4\. Run the application:



&#x20;  ```bash

&#x20;  python app.py

&#x20;  ```



5\. Open the local URL shown in your terminal.



\## Project Objective

To improve healthcare appointment management, support data-driven scheduling, and help healthcare providers identify appointments that may be missed.
